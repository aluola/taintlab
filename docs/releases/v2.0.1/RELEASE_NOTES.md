# v2.0.1 六项核心功能文档与演示

本补丁发行新增六项核心功能操作与验证手册、开发与交付过程说明、逐项证据矩阵，以及按 F01–F06 组织的 270 秒中文 Demo。冻结运行核心仍为 **2.0.0**；模型、权限策略、正式数据、实验判定与 3,672 条正式记录未改变，本轮没有重跑全部正式实验。

## 使用与下载

普通用户下载 `taintlab_project_light.zip`，解压后按 [README](https://github.com/aluola/taintlab/blob/v2.0.1/README.md) 完成首次安装和模型准备；日常双击根目录“启动项目.cmd”和“关闭项目.cmd”。界面为本机 `http://127.0.0.1:8501/`，日常不需要 npm 开发服务器。

仅 Windows 11 / Python 3.12 / NVIDIA RTX 4050 Laptop 6GB 路线经过当前验证，这不是测量得出的最低配置。首次依赖、官方 Qwen3-0.6B Q8_0 与固定 Windows CUDA llama.cpp 资源需要联网下载或按锁文件校验已有资源。权重、推理二进制、venv、node_modules、活跃会话、认证数据、PID、日志与原始录屏不在源码或轻量包内。

## 真实验证与边界

本轮实际操作四个正常工具、上传后读取和来源传播、通知确认/拒绝、四种攻击规则生成与执行。F03 使用正常任务的真实信息流拒绝记录，合法任务失败仍展示；F05 的直接与分段案例也保留失败与未完整接触事实。七个 Canary 正反/编码/分片/超界对照直接调用原检测器，是合成机制自检，不能计入模型 ASR。独立新内存采样覆盖四个代表任务，进程内存与设备显存分列。

发布前全套 Python 回归 **473 项通过、0 失败**，终端报告168.34秒，有一条依赖弃用提示；其后公开摘要引用修复另有4项定向回归通过。过程文档记录的先前465项和各定向检查均独立保留，重叠子集不相加。文档逐页渲染检查、视频全片解码/字幕音轨/关键画面/实际播放及最终打包结果，以附件中新哈希绑定的验收为准，不沿用 v2.0.0 结论。

公开来源适配集不是 BIPIA 或 InjecAgent 官方完整复现。扩展集完整策略 ASR **34/180**，无防御 **31/180**，不支持普遍降低攻击成功率；尚未证明污点追踪相对 policy_only 的独立收益。无防御也零 Canary 外泄，不能归因防御；目前没有完整策略阻断后安全完成全部合法任务实例。正常完成率含确认辅助，报告中分开列出自动与辅助部分。

本项目是本地模拟教学与研究平台。成员姓名、学号、实际分工、真实人工工时与自有代码许可证选择仍待补充；AI 或自动化时长不等于成员人工工时。v2.0.0 的 tag、视频、包和验收附件保持原样。
